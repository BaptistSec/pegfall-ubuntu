# Source and replacement

Pegfall source is supplied in Pegfall-0.20.0-source.zip. See BUILDING.md for the Python3.10 x86-64 build instructions. The companion Pegfall-0.20.0-dependency-sources.tar.gz contains the runtime sources, source checksums and upstream build recipes.

You may modify or replace LGPL components and rebuild against them. No restriction on replacement is imposed. The bundled application uses PyInstaller; the supported replacement route is rebuilding from source. See the platform component notices and full licence texts included here.
